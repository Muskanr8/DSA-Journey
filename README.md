# 🧠 DSA Journey

A structured collection of my **Data Structures & Algorithms** problem-solving journey, with solutions implemented in **Java**.

This repository documents my progress through coding patterns, algorithmic techniques, and problem-solving approaches using problems primarily from **LeetCode**.

## 🎯 Goal

Build strong problem-solving skills by learning DSA through **patterns**, rather than solving problems randomly.

## 📚 Learning Approach

I follow a pattern-based approach:

* Understand the underlying technique
* Learn common sub-patterns
* Solve problems from Easy → Medium → Hard
* Identify the pattern before coding
* Analyze time and space complexity
* Revisit problems for spaced repetition
